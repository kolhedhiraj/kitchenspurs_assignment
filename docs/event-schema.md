# Event schema

## Envelope

`POST /api/v1/events` accepts one event per request. The API assigns `source` from the credential, sets `received_at`, and persists the event only after validating its envelope.

```json
{
  "event_id": "c5cc5125-9a8d-45e6-bc8c-06457edf334e",
  "event_name": "page_view",
  "event_type": "page_view",
  "application_id": "restaurant-demo",
  "anonymous_id": "0a01b348-7ae9-4dbb-9489-1f0a426cf954",
  "user_id": null,
  "occurred_at": "2026-10-15T10:30:00Z",
  "properties": {},
  "context": {
    "path": "/menu",
    "url": "http://localhost:3000/menu",
    "referrer": "/",
    "title": "Menu",
    "user_agent": "browser user agent",
    "sdk_version": "0.1.0"
  }
}
```

| Field | Meaning |
| --- | --- |
| `event_id` | Required UUID generated by the caller; the unique idempotency key. |
| `event_name` | Required identifier, 1–100 characters, letters followed by letters, digits, `_`, `.`, `:`, or `-`. |
| `event_type` | `page_view`, `custom`, or `business`. Browser credentials cannot create business events. |
| `application_id` | Required and must match `ANALYTICS_APPLICATION_ID`. |
| `anonymous_id` | Optional browser-generated UUID stored in localStorage; not an account identity. |
| `user_id` | Optional application user identifier. The demo has no authentication and does not set it. |
| `occurred_at` | Required parseable event time. Normalized to UTC on write. |
| `received_at` | Server timestamp assigned by Laravel; clients cannot set it. |
| `properties` | Optional JSON object/array, limited to 100 top-level entries and 16 KB serialized. |
| `context` | Optional JSON object, limited to 32 top-level entries and 16 KB serialized. Includes page path/URL/referrer/title and SDK/user-agent metadata. |
| `source` | Set by Laravel from the ingestion credential (`browser` or `server`); never trusted from request JSON. |

The full HTTP body is limited to 64 KB. No IP address is stored. Context and properties are not intended for secrets or unnecessary personal information.

## Identity and uniqueness

Each browser application gets a UUID anonymous ID in localStorage. It persists across page loads for that browser and can be cleared by the visitor. Optional `user_id` is separate; this demo has no sign-in flow and does not assign a session ID. Dashboard unique visitors means `COUNT(DISTINCT anonymous_id)` among page-view events in the selected UTC date range; server events without an anonymous ID do not contribute.

## Authentication and security assumptions

Send a key in `X-Analytics-Key`:

- `BROWSER_INGESTION_KEY` is public and may be embedded in the browser app. It identifies this demo application; it is not a secret.
- `SERVER_INGESTION_KEY` is secret and used only by the Laravel server analytics client. Never expose it through `NEXT_PUBLIC_*` or browser bundles.

Laravel constant-time compares the key, derives source from it, requires the configured application ID, validates event names/types, limits payload/property sizes, and applies ingestion rate limiting. Read-only dashboard reports are unauthenticated for this local demo and should be protected before production use.

## Idempotency and timestamps

`event_id` has a unique database constraint. Reposting an existing event returns HTTP 200 with `duplicate: true` and creates no additional row; a new event returns HTTP 202. `occurred_at` represents client/business event time; `received_at` is assigned after request validation in UTC. Dashboard date filters are calendar dates interpreted as inclusive UTC days.

## Examples

Browser event:

```sh
curl -X POST http://localhost:8000/api/v1/events \
  -H 'Content-Type: application/json' \
  -H 'X-Analytics-Key: local-browser-key-change-me' \
  --data '{"event_id":"c5cc5125-9a8d-45e6-bc8c-06457edf334e","event_name":"menu_item_viewed","event_type":"custom","application_id":"restaurant-demo","anonymous_id":"0a01b348-7ae9-4dbb-9489-1f0a426cf954","occurred_at":"2026-10-15T10:30:00Z","properties":{"item_id":"pizza-margherita"},"context":{"path":"/menu"}}'
```

Server business event:

```sh
curl -X POST http://localhost:8000/api/v1/events \
  -H 'Content-Type: application/json' \
  -H 'X-Analytics-Key: local-server-secret-change-me' \
  --data '{"event_id":"8a9c4d6b-54ed-4e76-8273-a1a2c9d1a2ee","event_name":"order_created","event_type":"business","application_id":"restaurant-demo","occurred_at":"2026-10-15T10:30:00Z","properties":{"order_id":123,"amount":478,"currency":"INR","items_count":2}}'
```
